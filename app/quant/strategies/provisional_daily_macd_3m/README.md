# 正式策略：原MACD＋ADX14买入＋E2延迟卖出

稳定策略 ID：`provisional_daily_macd_3m_v1`

策略版本：`2.0.0`

## 日线观察池

日线 MACD 固定为 `(20, 100, 30)`，至少预热 130 根完整日线。设昨天和前天
收盘后的正式日线柱体为 `H(T-1)`、`H(T-2)`：

- 空仓且 `H(T-2) < 0`、`H(T-1) < H(T-2)`：今天进入买入观察池；
- 已持仓、满足 T+1，且 `H(T-2) > 0`、`H(T-1) > H(T-2)`：今天进入卖出观察池；
- 连续扩张期间每天重新判断，因此不需要事后知道哪一天是最终最长柱。

观察池只在当前交易日有效。收盘仍未触发时，当日观察结束，下一交易日根据最新两根
完整日线重新判断。账户已有待撮合信号时不再产生同股票的新信号。

## 三分钟盘中确认

三分钟只是检查频率，不计算三分钟 MACD。每根完整三分钟 K 线收盘后，用当时价格作为
今日临时收盘价，从昨天冻结的日线 EMA 状态独立试算今日临时日线 MACD `Ĥ(T,t)`。
同一天的三分钟价格不能作为多根日线连续递推。

- 买入：`Ĥ(T,t) < 0`，并且相对 `H(T-1)` 缩短至少 1%；
- 卖出：`Ĥ(T,t) > 0`，并且相对 `H(T-1)` 缩短至少 1%；
- 必须连续 3 根完整三分钟 K 线成立；任意一根失败，连续计数归零；
- 第三根收盘产生信号，下一根三分钟 K 线开盘尝试撮合。

临时柱体跨越零轴不触发本策略，因为它已经离开对应的绿柱谷底或红柱峰顶定义。
盘中信号一旦真实成交，不使用当天最终收盘结果撤销交易。

## ADX14买入与E2延期

ADX沿用已核对的Wilder公式，固定从2025-11-05开始预热并逐日追加。
盘前冻结A=ADX14[t−1]、B=ADX14[t−4]，端点是市场交易日；端点缺失不顺移替代。
Strong定义为A≥20且A>B，中性、弱或缺失均不允许新买入。
原MACD三柱买点已经产生后才应用门控，被拒绝信号记录为`rejected_adx`。

原MACD卖点出现后，只有Strong、当前已完成柱估算清算净收益>0、临时日线DIF>0且H>0，
才进入`DEFERRED_EXIT`。否则按原卖点提交退出。
延期中每根完整柱检查，任一资格失效或指标缺失就提交退出，不要求新原卖点。
`EXIT_PENDING`优先于趋势判断，T+1/跌停只延后成交，不撤销退出指令。
E2不在没有原卖点且未延期时提前退出。延期状态与起始时间跨日保存。

估算清算价使用当前已完成柱收盘价减不利滑点、限制在该柱范围内，并扣佣金和印花税；
入场成本包含实付买入佣金。该报价仅用于判断资格，实际成交仍取下一柱开盘。

## 成交和账户

- 每只股票初始独立 10 万元，买入按 100 股整数手使用本股可用现金；盈亏与剩余现金跨日累计，不补回10万元；
- 公开账户汇总仅纳入曾实际买入的股票，首次买入时纳入10万元本金，清仓后保留，重复买入不重复增加本金；未买入的固定池账户只用于观察和未来撮合；
- 双边佣金万一、卖出印花税万五、双边不利滑点万五；
- 滑点价格受成交 K 线真实最高价和最低价约束；
- 买入参考价达到涨停价时取消该买入信号，不保留次日兜底候选；
- 卖出参考价达到跌停价时保留原信号，顺延到第一根脱离跌停的三分钟 K 线；
- 买入成交日执行 T+1 锁定；常规卖出须进入日线卖出观察池；已延期持仓在E2资格失效时直接提交退出；
- 区间末持仓只按真实行情估值，不强制卖出；不增加其他止损、止盈或指标。
