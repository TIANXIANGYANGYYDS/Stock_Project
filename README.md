# Stock_Project

## 项目结构

Stock_Project/
├── app/
│   ├── api/            API 接口层
│   ├── core/           核心配置、基础组件
│   ├── crawlers/       股票数据采集模块
│   ├── db/             数据库连接与初始化
│   ├── models/         数据模型
│   ├── repositories/   数据访问层
│   └── services/       业务服务层
└── tests/              测试代码
