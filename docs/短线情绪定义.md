## 描述对象

| 层次 | 回答的问题 | 比较范围 |
| --- | --- | --- |
| 环境 | 当前赚钱、亏钱效应怎样，强势是在扩散还是收缩？ | 明确范围的市场或题材群体 |
| 题材 | 股票与哪些方向有关，哪些方向正在得到行情支持？ | 有来源和生效时间的成员关联 |
| 角色 | 一只股票在当前阶段、当前群体中发挥什么作用？ | 明确的题材或观察池 |

| 行为 | 股票已经出现了什么价格、成交和涨跌停变化？ | 当前可见的个股路径 |
| 条件预期 | 基于当前事实，后续要观察什么条件是否成立？ | 提出时固定的对象与观察区间 |

保留展示含义：市场为“对象、环境”；个股为“股票、题材、角色、关系、行为、预期”。数据截至时间、观察时间、范围、来源和质量用于解释这些字段。

## 环境

环境描述明确股票范围内，强势能否延续、新的强势是否出现并扩散，以及失败后的负反馈是否扩大。上涨家数反映参与广度，昨日强势股表现反映延续反馈，两者可以背离；不能把其中一个数值作为整个环境的替代。

本文的“赚钱效应、亏钱效应”指固定观察组的可核验价格表现及其延续、回撤，不等同于投资者实际盈亏，也不假定涨停股能够成交。当前价格相对昨收的涨幅、相对开盘的变化、相对已记录观察点的变化，应分别说明参考价格。

### 大盘环境

大盘环境回答：**在全市场范围内，短线强势的延续和扩散处于什么状态，失败后的负反馈有多广、多深？** 默认观察全 A 股；主板及各交易板块作为分项解释，切换范围后必须明确标识。指数涨跌只补充背景，不直接决定情绪结论。

| 观察维度 | 要回答的问题 | 可用证据与解释边界 |
| --- | --- | --- |
| 参与广度 | 走强是否得到较广股票参与，还是集中在少数股票？ | 上涨/下跌分布、涨幅中位数、强涨与大跌分布，并观察其变化。多数股票微涨不等于短线接力顺畅。 |
| 强势延续 | 上一交易日已识别的强势股票，今天能否保持表现？ | 分别观察昨首板、昨连板、昨高位板等固定组的开盘、当前表现和回撤，避免只看一个混合中位数。组间出现背离时保留背离。 |
| 新增与接力 | 新的强势是否出现，已有梯队是否延续？ | 新触板、新涨停、首板与晋级、不同高度的延续和失败；区分少数高板独撑与参与扩大。最高板高度不能单独代表整体强弱。 |
| 负反馈传播 | 失败是否由个别股票扩大到更多强势股、层级或方向？ | 昨强势组大跌/跌停、开板后的持续回落、回封后的保持、回撤分布随时间的变化。单只高位股下跌不足以判定全市场退潮。 |
| 结构与持续 | 改善来自广泛增强、方向轮动，还是少数股票集中支撑？ | 分板块、分高度与题材内成员的表现及连续观察。题材重叠成员先去重，不能把同一批股票上涨解释成多个独立方向扩散。 |

涨停接力是当前已有数据的一类观察组，不等于全部短线活动。没有涨停但持续走强的股票仍进入市场广度与价格分布；若增加趋势强势组的延续判断，须先明确当时可执行的入组与退出规则，不能事后挑选赢家。

### 题材环境

题材环境回答：**在事先确定的题材成员范围内，强势是否有延续、是否向更多成员扩散，原强势成员失效后是否出现持续负反馈？** 同时说明该题材相对可比市场的表现。题材成员关系是观察范围，不直接证明上涨原因。

| 观察维度 | 要回答的问题 | 可用证据与解释边界 |
| --- | --- | --- |
| 整体表现 | 该题材成员自身在走强还是走弱？ | 全体有效成员的涨跌分布、涨幅中位数、回撤和涨跌停分布。保留成员总数、有效样本数与覆盖率。 |
| 内部扩散 | 强势从少数成员扩展到更多成员了吗？ | 新增强势成员、参与比例变化及强势是否过度集中；对照全体成员和此前强势组。单股涨停或若干股票一直强，不直接证明扩散。 |
| 强势延续与结构 | 原有强势成员是否延续，新增成员是否形成支持？ | 事先固定的强势组反馈、首板与晋级、不同阶段成员的表现。成员前七与最高板不自动等于龙头或核心。 |
| 相对表现 | 是否强于同时间、可比组成的市场背景？ | 对照成员所属交易板块等可比基准，区分随市场普涨、相对走强与下跌中抗跌。题材跌得较少可以相对强，但仍可能绝对走弱。 |
| 负反馈与持续 | 原强势是否仅短时受阻，还是损失持续扩散？ | 原强势组回撤、开板后表现、回封保持、其他成员是否继续转弱，以及随后有无恢复。一次回封不足以确认题材修复。 |

题材环境独立判断，允许“全市场偏弱、个别题材持续走强”以及“全市场走强、某题材持续退潮”。市场背景影响相对表现的解释，不覆盖题材自身事实。题材内部强势也不自动取得跨题材的“主线”身份。

题材大小、成员集中度及交易板块组成必须进入证据解释。展示数量时同时展示占比和样本；小题材不能凭一个涨停获得与大样本相同的确认程度。数据覆盖完整与样本充分是两个条件，均须检查。

### 当前环境定义：两套六阶段

大盘与题材使用不同状态集合，环境每 5 分钟评估一次；新阶段未确认前，当前阶段不清空。进入、保持、确认次数、转换优先级统一以[初版判定规则](短线环境判定规则.md)和对应源码为准。

大盘关注市场机会、亏钱效应和方向集中程度，指数只作背景：

| 大盘阶段（由好到坏） | 核心含义 | 必须区分的边界 |
| --- | --- | --- |
| 行情沸点 | 市场整体强势，统计主线明确，是最高档 | 指数上涨或少数高位独撑不能单独构成沸点 |
| 行情过热 | 多个去重后的活跃方向竞争 | 同一批股票属于多个概念，不算多个独立方向 |
| 行情微热 | 上涨广度恢复，出现较大范围普涨 | 可以同时出现旧强势组亏损，不要求所有方向同步 |
| 行情微冷 | 整体走弱、普涨收缩或旧主线价格转弱 | 未确认过主线时不补造主线退潮 |
| 行情过冷 | 广泛亏钱与重负反馈，抛压明显扩散 | 进一步恶化可转冰点，不能把此方向叫修复 |
| 行情冰点 | **最低档：上涨机会极少、全市场负反馈极重**，可能只剩少数方向抱团 | **低活跃、横盘或跌速放缓本身不是冰点；冰点→过冷属于改善**，不保证即将反转 |

题材关注内部扩散与板位接续。2026-10-18 按用户确认，首板为 **1 板**、中板为 **2—4 板**、高板为 **5 板及以上**；四板仍属于中板。固定中位晋级组对应昨日 1—3 板、今日目标 2—4 板；固定高位组取昨日已确认至少 5 板。属于业务约定，不是行业统一标准：

| 题材阶段 | 核心含义 | 必须区分的边界 |
| --- | --- | --- |
| 启动 | 多只新首板出现，并有成员跟随 | 不要求昨日已存在足够强势股；单只涨停不足以启动 |
| 主升 | 大部分成员走强，首板和中板共同支持；常规要求多只中板，初版另允许更强普涨与单中板接续 | 单中板分支须有更高的广度、中位数、强势占比及同组首板门槛；只有涨幅、没有板位接续时不强称接力主升 |
| 分歧 | 中位竞争、部分晋级部分受阻，或强势参与明显收缩，同时仍有阶梯支持 | 有既有活跃背景；一次开板、尚未尝试晋级的平盘股不自动成为失败 |
| 高潮 | 高板、中板、首板共同支持，成员广泛参与；初版允许同限幅组内板位缺档 | 单只高板独撑不算高潮；不同限幅的首、中、高板不能拼成同一组支撑 |
| 退潮 | 高位或核心负反馈与整体抛压相互印证；启动失败也可能进入 | 高位股盘中尚未涨停不等于收盘断板；单只股票受阻不代表整个题材退潮 |
| 整理 | 涨停少，最近一段时间波动与新增抛压都小 | 允许跌后的低位横盘；不要求日内涨幅回到零，也不把持续下跌叫整理 |

“集中抱团、主线明确、主线退潮”需要独立的结构证据；“当前主阶段、转换候选、保持证据、数据质量”分别保留。“转换待确认”只描述候选，“数据不足”只描述行情质量，均不替代已经建立的主阶段。连续展示的是有记忆的环境区间，不表示旧阶段的所有进入条件始终成立。

### 题材环境的验证目标（2026-10-20 确认）

当前目标是确认**环境阶段的含义、决定条件和转换时点是否符合实际题材行情及业务预期**。历史回放用于检查分类是否准确、是否及时、是否稳定。交易收益率、是否买到某只连板股、选股排名、仓位和成交限制，均不能作为环境定义正确与否的判据。前面的交易实验只保留为辅助记录，不据其收益高低调整环境参数。

| 阶段 | 应核对的实际行情证据 | 重点检查的定义偏差 |
| --- | --- | --- |
| 启动 | 新首板集中出现，开始有跟随扩散，能区分单股异动；整理或退潮后均可重新启动 | 已有明确启动形态，却被前态路径限制阻挡；或单只涨停就触发启动 |
| 主升 | 题材参与扩大、成员多数走强，2—4板接续形成，强势仍在保持 | 仅因龙头上涨判定整体主升；或广度和接力已持续走弱，仍长期延续主升标签 |
| 分歧 | 同一轮行情中部分晋级、部分受阻，强弱分化有具体股票和持续证据 | 只因指数下跌、普通波动或一个股票短暂开板就判分歧；把广泛崩坏仍称为分歧 |
| 高潮 | 5板及以上高位股、中板主力、低位补充共同支撑，题材结构进入高活跃阶段 | 单只高板代替整体结构；或者追加过强的全体普涨门槛，排除原业务定义认可的结构性高潮 |
| 退潮 | 原有强势及核心群体负反馈扩散，接力破坏、成员抛压持续，或启动失败恶化 | 等多数核心彻底大跌才变更；或把正常晋级分化直接判为退潮 |
| 整理 | 活跃度低，近期波动收敛，新增抛压少，缺少有效接力 | 把持续下跌、加速转弱或仅短暂跌速放缓归入整理 |

以上是语义验收依据，不是新一轮已确认的数值阈值。验证先列出当时可见的首/中/高板结构、晋级与失败股票、上涨广度、负反馈及持续时间，再对照阶段；单个指标或代码门槛通过不自动证明业务含义正确。对有争议的区间，应先确定参考阶段和可接受的确认延迟，再评估规则，避免用算法自身标签证明算法正确。已经查看的样本可以用于澄清含义，之后还需用未参与调参的题材或日期验证。

连续性要求每个时点有已有阶段可解释地延续，但应同时检查阶段保持证据、转出条件及滞后时长。它不要求每轮行情都完整走遍六个阶段，也不允许用“保持连续”掩盖长期缺少支持的标签。高潮是当时的环境描述，不保证对应事后最高价；后续价格变化可辅助核对演变，不得把未来事实倒填到历史判定。

### 初版回放与已知边界

[完整对照报告](../.local/analysis/environment_v42_v24_review_20261020/大盘V4_2与题材V2_4_优化完整对照.html)保留到 2026-10-20：大盘从 9 月 1 日起 30 个交易日；医药、农业、消费、传媒、电池从 7 月 1 日起各 74 个交易日，共 18,800 个五分钟窗口。每天判断截至 14:55，共 47 窗；分钟输入到 15:00。报告可查看各日完整阶段、转换条件、首中高板股票及支持证据。

初版改善了大盘冰点恢复、过冷恢复、主线失效后的降级，以及题材持续失效退出、强普涨时单中板接续、新首板周期承接、整理保持与新增风险识别。原有九个问题审查时点得到改善，电池 9/29 启动、9/30 分歧、10/8 主升、10/12 退潮四个正例的确认时点保留。它们属于已查看样本的回归验证，不是独立准确率证明。

原始输入以实时分钟库为主，早期缺口含历史分钟回溯补全；成员范围使用冻结题材名单，不声称每日历史归属已还原。行情时间与主机时间分开，约五分钟的主机偏差不用于平移历史分钟。收盘事实只更新后续固定组，不倒填到当日早盘。

本轮冻结时保留以下问题，尚未改变对应规则：

- **保持证据未知：**18,800 窗中共 2,067 窗，2,063 窗来自整理状态在开盘或午后前 30 分钟的滚动指标预热。主阶段仍连续保留，不能把它们全部解释成数据库漏采。
- **局部质量传播：**10/20 大盘有两窗受一个小方向的个股分钟缺口影响；消费有两窗受固定高位组停牌成员的价格未知影响。应后续分别处理局部结构覆盖、固定风险组停牌和提示语。
- **语义边界：**题材仍有较长的保持失效区间、整理/退潮往返和高潮边界争议；初版不等于这些问题已解决。后续按独立参考阶段与确认时间验收，不用交易收益反推标签。

## 题材与主线

题材成员资料保留在[短线题材分类匹配库](短线题材分类匹配库.json)，使用边界见[题材基础资料](短线题材使用约定.md)。一股可以有多个关联，成员归属不能直接证明本次上涨的主要原因。

“主线”用于描述在一定阶段持续得到较广参与、核心及后续响应支持的市场方向。2026-10-17 的 V4 实验规则结合去重贡献、规模校正、相对强度、涨停或昨日固定强势组反馈，连续六个窗口确认统计主线；规则已纳入 V4.2，2026-10-21 已由 `market.emotion.structure` 返回服务结果。成员关联不证明实际上涨原因。允许暂时无法确定主线，也允许多条方向并存。

## 角色

角色描述阶段作用。阶段身份、当前是否仍有支持、当日强弱、最近退出及历史身份应分别理解。

| 名称 | 保留含义 | 证据边界 |
| --- | --- | --- |
| 前排 | 在同一比较范围内主动推进或相对领先，且有阶段结构支持。 | 一次冲高或静态涨幅排名不足以确立持续作用。 |
| 当前龙头 / 阶段领涨 | 在明确范围内处于阶段领先位置，当前作用仍有证据支持。 | 需要领先、结构、流动性及响应或此前已完成表现等可核查依据，不能只凭最高板数授予身份。 |
| 容量核心 | 在该群体中持续承担较大的成交参与和流动性作用。 | 成交额大不直接证明资金护盘或稳定承接。 |
| 跟随 / 后排 | 在已有先行者之后出现响应，并有相对落后或后发证据。 | 没有识别出角色的股票不能一律叫后排。 |
| 原核心 / 原龙头 | 此前取得过核心身份，但当前作用已经退出。 | 保留历史记录用于观察，不继续冒充当前在位者。 |
| 待确认 | 证据不足，尚未形成明确角色。 | 允许空缺，不要求每个池子每天必须有龙头。 |

池内阶段领涨、题材龙头、市场总龙头是不同范围的称谓。用固定消费池得到的领先现象，应保留其池内范围；行业代理也不能直接升级为当日交易题材。

已有身份可以跨日作为观察背景。当天仍须核对新支持和反证；单个短窗口不再上涨不等于退出，当日转弱也不等于角色消失。失去当前作用后，历史身份仍然保留。

确认与退出应各自记录依据及发生时间。连续观察的次数和具体阈值留待后续重新设计，本次不继承旧实验参数。

## 行为

行为描述已经发生的变化，分别看日内表现、短时变化和涨跌停路径。某只股票可以同时处于“阶段领涨、日内转弱、短时反弹”等不同层次的状态。

| 名称 | 保留含义 |
| --- | --- |
| 日内强势 / 弱势 | 相对当日可比参考价、同行表现及自身回撤，描述当日强弱。 |
| 短时推进 / 回落 / 横盘 | 描述最近有效观察区间内的价格变化；不直接取消阶段角色。 |
| 高位维持 | 已取得较高位置后保持已有结构，即使短时价格变化很小。 |
| 突破 / 失守 | 越过或跌破事先确定的结构位置；位置不能随事后结果移动。 |
| 弱转强 / 转弱 | 原有强弱状态发生变化，并有新的结构及相对表现证据。 |
| 分歧 / 修复 | 原推进受到考验；修复需要已经观察到恢复，而非仅因跌后反弹就认定成功。 |
| 触及涨停 / 跌停 | 有效价格达到当日对应限价；限价未知时不能凭约涨幅替代。 |
| 分钟末涨停 / 跌停 | 有效完整分钟的末价处于对应限价，只说明该采样时点的价格状态。 |
| 打开 / 回封 | 连续有效观测中，限价状态消失或重新出现；缺口不能拼接成价格路径。 |
| 首板 / N 板 / 断板 | 连续交易日收盘涨停事实及当日暂定进展；盘中与收盘确认分别说明。 |
| 一字 / 地天 / 天地 | 有完整路径时描述对应过程；只有日线时只能保留四价或触及与收盘的代理含义。 |

2026-10-21 已实现的事件在原有触板、封板、开板、回封和跌停基础上，新增暴力拉升、急速下跌、快速反弹、高台跳水、放量异动、打开跌停板。具体窗口、幅度、成交额门槛、连续性与冷却规则见[事件接口](短线情绪接口.md#get-events)。这些事件描述实际观测的价格和成交额变化，不等同于角色变化，也不据此认定主动买入或主力资金。

分钟 OHLC 无法还原每次分钟内开板、连续封单、盘口排队或实际成交。真实零成交与缺少记录分开；未知的停牌、板数、限价和身份不补成零。

## 关系

| 名称 | 保留含义 |
| --- | --- |
| 先行 / 跟随响应 | 一方先推进，另一方随后出现相关变化；记录时间次序及共同市场变化。 |
| 共振 | 同一时段共同推进；不据此指定谁带动谁。 |
| 补涨候选 | 已有核心仍存在，另一成员后启动且此前阶段位置较低，随后表现保持。 |
| 助攻候选 | 核心受到考验时，其他相关成员推进或维持群体表现，描述观察到的协同。 |
| 竞争候选 | 同范围内具有接近领涨地位的股票出现持续相对强弱变化。 |
| 卡位候选 | 已存在竞争，挑战者自身主动推进并取得新的相对领先位置。 |
| 接棒 | 新作用建立、原作用退出之后出现核心更替；不直接推断资金迁移。 |
| 分离候选 | 此前已有联系，随后双方出现持续的方向分化。 |
| 带动候选 | 多个独立推进事件及其后续响应提供的时序联系。 |

一次推进后多只股票响应，不等于多个独立推进事件。共同上涨、相关性和先后顺序都不能单独证明因果或资金意图。所有关系需要对象、范围、形成时点和结束依据。

## 条件预期

预期保留为可验证的观察条件，例如结构保持、相对推进、后续成员响应、分歧修复和限价状态延续。提出时固定对象、参考位置、观察区间、成立及失效条件。

观察只从提出之后开始。已完成、已失效、仍待观察、因缺失无法判断应分别记录；不能删除失败案例或用区间结束后的价格补交答案。目标完成、角色恢复和交易盈利是不同概念。

## 数据与时间边界

- 保留原始行情、证券属性、交易日历、来源及真实采集时间；基础统计口径见[每日基础数据留存](情绪每日入库.md)。
- 日线形成收盘事实，分钟记录形成当时路径；当天收盘结果不能倒填到当天早盘。
- 行情发生时间、系统实际收到时间、作出判断时间分别保留。事后补数仅用于明确说明口径的历史观察。
- 涨跌停判断采用对应日期、证券制度和价格口径；前复权价格不能直接替代当日原始限价。
- 比较范围先明确，数据不足保留未知。不得按后来的涨停股、盈利股票或成功案例倒选成员。
- 概念定义不自动产生评分、买卖信号、仓位或收益承诺。后续若重新实现，应从这些含义和可观测证据重新确定规则。
