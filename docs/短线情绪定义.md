## 描述对象

| 层次 | 回答的问题 | 比较范围 |
| --- | --- | --- |
| 环境 | 当前赚钱、亏钱效应怎样，强势是在扩散还是收缩？ | 明确范围的市场或题材群体 |
| 题材 | 股票与哪些方向有关，哪些方向正在得到行情支持？ | 有来源和生效时间的成员关联 |
| 角色 | 一只股票在当前阶段、当前群体中发挥什么作用？ | 明确的题材或观察池 |
| 关系 | 两只股票之间出现了什么先后、竞争或协同现象？ | 明确双方、比较范围和发生时点 |
| 行为 | 股票已经出现了什么价格、成交和涨跌停变化？ | 当前可见的个股路径 |
| 条件预期 | 基于当前事实，后续要观察什么条件是否成立？ | 提出时固定的对象与观察区间 |

保留展示含义：市场为“对象、环境”；个股为“股票、题材、角色、关系、行为、预期”。数据截至时间、观察时间、范围、来源和质量用于解释这些字段。

## 环境

环境依据群体广度、强弱分布、核心反馈、接力表现及扩散收缩描述。市场环境和题材环境分别观察；单只股票涨停不自动改变整个市场的环境。

| 名称 | 保留含义 |
| --- | --- |
| 试错整理 | 强势和亏损传播均不明显，局部尝试尚未形成持续扩散。 |
| 扩散发酵 | 强势从少数股票向更多成员扩散，参与范围改善。 |
| 主升 | 较广的强势参与得到核心或接力表现支持，并能维持。 |
| 主升中分歧 | 此前存在主升或扩散，随后参与收缩、核心分化或接力受损。 |
| 震荡分化 | 强弱并存，不同成员或方向的表现分化，缺少一致推进。 |
| 情绪低迷 | 强势参与稀少，上涨范围有限，弱势或亏损反馈较突出。 |
| 退潮 | 亏损效应扩大，原强势群体或核心地位持续受损。 |
| 退潮中修复 | 退潮背景下出现广度恢复、亏损收敛；是否进一步转强需要继续观察。 |
| 冰点 / 高潮 | 描述极端低迷或极端活跃特征；本身不证明底部或顶部。 |

这些状态没有固定的循环顺序。“数据不足”表示无法判断；“待确认”表示证据尚未达到确认要求；“状态未分类”表示数据可用但现有定义无法覆盖。三者含义不同。

## 题材与主线

题材成员资料保留在[短线题材分类匹配库](短线题材分类匹配库.json)，使用边界见[题材基础资料](短线题材使用约定.md)。一股可以有多个关联，成员归属不能直接证明本次上涨的主要原因。

“主线”用于描述在一定阶段持续得到较广参与、核心及后续响应支持的市场方向。此前未完成跨题材主线确认规则；本次只保留这个语义，不指定主线评分、排名或自动确认办法。允许暂时无法确定主线，也允许多条方向并存。

## 角色

角色描述阶段作用。阶段身份、当前是否仍有支持、当日强弱、最近退出及历史身份应分别理解。

| 名称 | 保留含义 | 证据边界 |
| --- | --- | --- |
| 前排 | 在同一比较范围内主动推进或相对领先，且有阶段结构支持。 | 一次冲高或静态涨幅排名不足以确立持续作用。 |
| 当前龙头 / 阶段领涨 | 在明确范围内处于阶段领先位置，当前作用仍有证据支持。 | 需要领先、结构、流动性及响应或此前已完成表现等可核查依据，不能只凭最高板数授予身份。 |
| 容量核心 | 在该群体中持续承担较大的成交参与和流动性作用。 | 成交额大不直接证明资金护盘或稳定承接。 |
| 跟随 / 后排 | 在已有先行者之后出现响应，并有相对落后或后发证据。 | 没有识别出角色的股票不能一律叫后排。 |
| 原核心 / 原龙头 | 此前取得过核心身份，但当前作用已经退出。 | 保留历史记录用于观察，不继续冒充当前在位者。 |
| 待确认 | 证据不足，尚未形成明确角色。 | 允许空缺，不要求每个池子每天必须有龙头。 |

池内阶段领涨、题材龙头、市场总龙头是不同范围的称谓。用固定消费池得到的领先现象，应保留其池内范围；行业代理也不能直接升级为当日交易题材。

已有身份可以跨日作为观察背景。当天仍须核对新支持和反证；单个短窗口不再上涨不等于退出，当日转弱也不等于角色消失。失去当前作用后，历史身份仍然保留。

确认与退出应各自记录依据及发生时间。连续观察的次数和具体阈值留待后续重新设计，本次不继承旧实验参数。

## 行为

行为描述已经发生的变化，分别看日内表现、短时变化和涨跌停路径。某只股票可以同时处于“阶段领涨、日内转弱、短时反弹”等不同层次的状态。

| 名称 | 保留含义 |
| --- | --- |
| 日内强势 / 弱势 | 相对当日可比参考价、同行表现及自身回撤，描述当日强弱。 |
| 短时推进 / 回落 / 横盘 | 描述最近有效观察区间内的价格变化；不直接取消阶段角色。 |
| 高位维持 | 已取得较高位置后保持已有结构，即使短时价格变化很小。 |
| 突破 / 失守 | 越过或跌破事先确定的结构位置；位置不能随事后结果移动。 |
| 弱转强 / 转弱 | 原有强弱状态发生变化，并有新的结构及相对表现证据。 |
| 分歧 / 修复 | 原推进受到考验；修复需要已经观察到恢复，而非仅因跌后反弹就认定成功。 |
| 触及涨停 / 跌停 | 有效价格达到当日对应限价；限价未知时不能凭约涨幅替代。 |
| 分钟末涨停 / 跌停 | 有效完整分钟的末价处于对应限价，只说明该采样时点的价格状态。 |
| 打开 / 回封 | 连续有效观测中，限价状态消失或重新出现；缺口不能拼接成价格路径。 |
| 首板 / N 板 / 断板 | 连续交易日收盘涨停事实及当日暂定进展；盘中与收盘确认分别说明。 |
| 一字 / 地天 / 天地 | 有完整路径时描述对应过程；只有日线时只能保留四价或触及与收盘的代理含义。 |

分钟 OHLC 无法还原每次分钟内开板、连续封单、盘口排队或实际成交。真实零成交与缺少记录分开；未知的停牌、板数、限价和身份不补成零。

## 关系

| 名称 | 保留含义 |
| --- | --- |
| 先行 / 跟随响应 | 一方先推进，另一方随后出现相关变化；记录时间次序及共同市场变化。 |
| 共振 | 同一时段共同推进；不据此指定谁带动谁。 |
| 补涨候选 | 已有核心仍存在，另一成员后启动且此前阶段位置较低，随后表现保持。 |
| 助攻候选 | 核心受到考验时，其他相关成员推进或维持群体表现，描述观察到的协同。 |
| 竞争候选 | 同范围内具有接近领涨地位的股票出现持续相对强弱变化。 |
| 卡位候选 | 已存在竞争，挑战者自身主动推进并取得新的相对领先位置。 |
| 接棒 | 新作用建立、原作用退出之后出现核心更替；不直接推断资金迁移。 |
| 分离候选 | 此前已有联系，随后双方出现持续的方向分化。 |
| 带动候选 | 多个独立推进事件及其后续响应提供的时序联系。 |

一次推进后多只股票响应，不等于多个独立推进事件。共同上涨、相关性和先后顺序都不能单独证明因果或资金意图。所有关系需要对象、范围、形成时点和结束依据。

## 条件预期

预期保留为可验证的观察条件，例如结构保持、相对推进、后续成员响应、分歧修复和限价状态延续。提出时固定对象、参考位置、观察区间、成立及失效条件。

观察只从提出之后开始。已完成、已失效、仍待观察、因缺失无法判断应分别记录；不能删除失败案例或用区间结束后的价格补交答案。目标完成、角色恢复和交易盈利是不同概念。

## 数据与时间边界

- 保留原始行情、证券属性、交易日历、来源及真实采集时间；基础统计口径见[每日基础数据留存](情绪每日入库.md)。
- 日线形成收盘事实，分钟记录形成当时路径；当天收盘结果不能倒填到当天早盘。
- 行情发生时间、系统实际收到时间、作出判断时间分别保留。事后补数仅用于明确说明口径的历史观察。
- 涨跌停判断采用对应日期、证券制度和价格口径；前复权价格不能直接替代当日原始限价。
- 比较范围先明确，数据不足保留未知。不得按后来的涨停股、盈利股票或成功案例倒选成员。
- 概念定义不自动产生评分、买卖信号、仓位或收益承诺。后续若重新实现，应从这些含义和可观测证据重新确定规则。
