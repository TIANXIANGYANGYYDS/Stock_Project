# 策略1低波动、低换手增量验证

本轮回答：在策略1原有买入信号上增加低波动、低换手过滤，是否改善整条账户路径。它与“按因子挑一组股票，每五日调仓”的上一轮研究不同。

窗口为2026-07-01至2026-11-06，87个交易日；沿用期初冻结的5,530只股票。每股独立10万元，现金只供本股使用，无新增资金，不跨股票调配。无交易账户也保留在总收益分母中。

## 固定规则

保留MACD 20/100/30、130日预热、1%收缩、连续三根三分钟确认、ADX14≥20且高于三个市场交易日前的值，以及E2延迟退出。下一根三分钟开盘成交，保留T+1、100股整手、涨跌停和跨日待成交处理。

在看到本轮完整路径结果前固定8组，正常成本、双倍成本分别运行，共16条组合：

| 场景 | 在原买入规则上的附加条件 |
|---|---|
| baseline | 无 |
| vol20_q20 / vol20_q40 | 20日波动率排名最低20% / 40% |
| vol60_q20 / vol60_q40 | 60日波动率排名最低20% / 40% |
| turn20_q20 / turn20_q40 | 20日平均换手率排名最低20% / 40% |
| vol60_turn20_q40 | 60日波动率和20日平均换手率均最低40% |

排名只用信号日前完整日线，在冻结股票池计算，并列取平均排名；不足80%覆盖时保持缺失，缺失不通过附加门槛。已提交订单沿用提交日判断，不能在成交日重新筛选。卖出及E2状态机不受附加买入过滤影响。

每个场景独立累计现金、持仓、盈亏及延期状态。过滤会使账户后来出现新买点，不能只删除基线交易来替代回放。实际路径成交与同批原买点的保留/剔除诊断分表保存。

## 价格与分钟输入

- 日线来自正式服务使用的stock_daily_detail，使用完整保存历史初始化MACD，ADX从正式规则固定的2025-11-05起递推。
- 8月20日前读取stock_history_3m_bars_ths_forward_stage的原生80根三分钟网格。
- 部分前复权包含现金分红扣减，不能只按比例拼接。historical_price_basis.py仅用前一交易日两侧OHLC确定平移/缩放，再核验当日完整OHLC。当前日价格只验证既定转换，不重新拟合转换参数或决定买卖条件。
- 转换失败、网格不完整或当日发生无法核验的价格基准变化时保留缺失。转换结果明确标为历史口径转换，不冒充当时首次采集的价格。
- 8月20日后优先从实际一分钟连续聚合三分钟，复用正式聚合器。有部分缺口时，历史整日必须通过已有分钟重叠价格核验才可替代。
- 前收参考价优先使用当时行情值；缺失时调用原有严格恢复函数核验日线涨跌额、涨跌幅和前后收盘。无法核验时禁止撮合。
- 从每股最早可能通过原MACD/ADX买点起审计分钟。没有任何可能买点的账户保持现金，不删除账户。
- 缺行情持仓可能沿用最后已知价格，逐日披露旧价估值金额和比例，不能解释为成功卖出。

历史复权版本、公司行为、日线修订、真实订单簿排队和容量仍限制解释，本轮是影子研究，不能宣称可按相同价格实盘成交。

## 评价口径

首要比较全部固定账户的净收益、最大回撤、已实现与未实现收益；其次看交易质量、大赢家保留及成本敏感性。

Alpha使用同日期上证日收益回归，无风险主假设年化0%，HAC滞后5日。增量Alpha是“候选日收益−原策略日收益”对上证日收益的回归截距；7个候选主检验一起做BH校正。此前全因子搜索已经使用这个窗口，本轮q值不能抹去此前选择过程，本窗口不是独立OOS。

“降低仓位对照”将原策略日收益乘以候选/原策略的全期平均仓位比。这个比例含全期信息，只是事后归因诊断，不是可预先交易的规则。

月度及四段时间对照沿用连续账户，不重置本金、不强制清仓。闭合胜率、闭合最差5%均值只用已卖出交易；期末持仓单列市值结果。大赢家保留率使用原策略闭合收益最高5%的交易，并与原买点保留率一起看。

另做共同完整行情子样本敏感性：统一剔除任一有日线却缺完整分钟/前收参考的股票，以及任一场景曾持仓遇到缺口的股票。所有候选与基线使用相同剩余股票，本轮为4,899只。这个筛选用了事后数据质量，可能带来存续偏差，仅作敏感性检查，不替代全池主结果。

正式账本从8月20日开始，本轮从7月1日启动；初始时点与后续持仓不同，不能直接拿两者收益率判断系统漂移。

方法参考：[CFA Institute：Jensen Alpha](https://rpc.cfainstitute.org/-/media/documents/code/gips/measures-risk-adjusted-return.pdf)、[NBER：多信号回测的选择偏差](https://www.nber.org/papers/w21329)。
