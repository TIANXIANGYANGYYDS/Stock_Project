# 量化策略一：原MACD＋ADX14买入＋E2延迟卖出

稳定策略ID为`provisional_daily_macd_3m_v1`，正式版本2.0.0。
策略规则见`app/quant/strategies/provisional_daily_macd_3m/README.md`，运行与数据口径见
`app/quant/README.md`和`docs/量化影子盘上线运行手册.md`。

原MACD日线观察及三柱确认保留。买点另须满足ADX14[t−1]≥20且高于ADX14[t−4]。
原卖点出现时检查E2资格：ADX强、估算清算净收益>0、临时DIF>0且H>0才延期；
延期资格失效即提交退出。待卖指令不会因ADX恢复撤销，继续遵守次柱成交、T+1、跌停顺延。

正式账本从2026-09-03空仓开始，每股10万元独立累计盈亏，汇总包括无交易账户。
历史补录使用真实采集行情并标注补录时间；实时记录持续由现有调度器生成。
系统为影子盘，记录的是模拟成交，不是真实券商成交。
