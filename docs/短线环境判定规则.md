## 共用口径

| 符号 | 含义 |
| --- | --- |
| r10 | 按当日涨跌停价分段标准化到 ±10 的涨幅，不等同所有股票的原始涨跌幅 |
| N | 当前有效成员数量；覆盖率分母另保留应有成员数 |
| B | 上涨股票占比，使用 0—100 |
| M | 全体有效成员 r10 中位数 |
| U | r10≥3 的成员占比 |
| D3 / D5 | r10≤−3 / r10≤−5 的成员占比 |
| F / 中板 / 高板 | 首板 1 板、中板 2—4 板、高板 5 板及以上；盘中为当时的候选连板 |
| A30 / V30 | 30 分钟个股 r10 振幅 / 变化的中位数 |
| Q10 | 最近 10 分钟 r10 下降至少 1.5 的成员占比 |

每 5 分钟评估一次。一个完整窗口需要五个连续且必要判据已知的分钟点；同一整套条件至少满足 4/5 点，且最后一点满足。未知不当作失败或安全。午休、隔夜、缺口重置连续确认，已经建立的主阶段保留到下一阶段确认；正式展示前须有同版本状态或真实历史预热。

2026-10-21 修复数据质量传播：大盘分钟点要求全市场有效覆盖至少 98%，不再因单个板块不足 98% 而直接否决整个大盘窗口。板块覆盖仍单独返回，方向及题材自己的覆盖、固定风险组完整性要求不变。`emotion.data_quality` 返回本窗口全市场最低覆盖、各板块最低覆盖及不完整方向；这项调整不改变下述阶段阈值。分钟边界可使用此前已经收到、来源时间早于边界且不超过 30 秒的有效报价；不使用边界后的新价格，不跨午休或隔夜延用缓存。收盘正式定稿仍执行独立的全市场和各板块覆盖检查。

普通 10%、20%、30% 限幅分别检查板位支撑，不能跨限幅组拼阶梯。当前规则要求关键股票在窗口内稳定出现；不要求 1 到最高板每个高度都有股票。涨停以对应日期的有效限价识别，收盘事实只用于随后时点。

## 大盘 V4.2

从好到坏：**沸点 ＞ 过热 ＞ 微热 ＞ 微冷 ＞ 过冷 ＞ 冰点**。指数表现作为背景，不直接决定阶段。

| 目标 | 普通进入条件 | 连续完整窗口 |
| --- | --- | ---: |
| 沸点 | B≥55、M≥0.5、U≥8、D5<5，且此前确认的统计主线仍有保持支持 | 2 |
| 过热 | B≥60、M≥0.5、U≥10、D5<5，活跃方向≥3 | 2 |
| 微热 | B≥55、M≥0、D5<5 | 2 |
| 微冷：下行 | B≤45、M≤−0.5 | 2 |
| 微冷：收缩 | 当前偏热，B<50、M<0 | 3 |
| 微冷：旧主线转弱 | B<55、M<0.5；最近五个已观察交易日内退出的旧主线方向 B≤45、M≤−0.5、D5≥10 | 2 |
| 过冷：深跌 | B≤35、M≤−1、D5≥6 | 2 |
| 过冷：普跌 | B≤15、M≤−1.5、D3≥15 | 2 |
| 冰点 | B≤10、M≤−2，且 D3≥25 或 D5≥10 | 2 |

急剧过冷：B≤25、M≤−1.5、D5≥10；急剧冰点：B≤5、M≤−3、D5≥15。两者均只需一个完整窗口。

| 当前阶段 | 保持条件 |
| --- | --- |
| 沸点 | B≥45、M≥0、U≥5、D5<6，原主线保持有支持 |
| 过热 | B≥50、M≥0、U≥7、D5<6，活跃方向≥2 |
| 微热 | B≥45、M≥−0.3、D5<6 |
| 微冷 | B<60、M<0.5 |
| 过冷 | B<40，且 D5≥6 或 M≤−1 |
| 冰点 | B<15、M<−1.5，且 D3≥20 或 D5≥8 |

普通最短保持为四个有效窗口（20 个交易分钟）。确认后的负向微冷/过冷/冰点转换可提前；改善方向不能借用该例外。偏热内部降级另须原保持连续两窗失效。过冷恢复要求 B≥25、M>−1.5、D5<6 连续两窗；冰点恢复要求冰点保持明确失效连续两窗。

正常路径优先。如果没有正常目标，原保持明确失效两窗、目标承接连续两窗成立且满足最短保持后，允许：

| 承接方向 | 额外证据 |
| --- | --- |
| 冰点→过冷 | 冰点恢复且过冷保持成立 |
| 冰点/过冷→微冷 | 过冷恢复条件与微冷保持同时成立 |
| 沸点/过热→微热 | 微热保持成立 |
| 偏热→微冷 | 微冷保持成立 |

重叠条件选择顺序为冰点、过冷、沸点、过热、微热、微冷；这是执行优先级，不是好坏排序。不强制逐档转换。

### 统计方向与主线

方向在盘前冻结；高度重叠的题材先合并，同一成员属于 k 个方向时各分配 1/k 权重。C 为方向强涨贡献占比，L 为该贡献相对方向基础成员权重的富集倍数，相对强度为方向 M−市场 M。

- 活跃方向：有效样本至少 10，覆盖至少 98%，B≥60、M≥0.5、U≥15、加权强涨贡献≥10。
- 主线分钟候选：市场和方向质量合格，市场强涨家数≥30；方向 N≥20、B≥70、M≥1、U≥20、加权强涨贡献≥10、C≥10、L≥2、相对强度≥0.8。
- 结构支持：当前涨停至少三只；或昨日固定强势组至少三只、来源和当前覆盖均合格，该组 M≥0、失败比例上界≤20%。未知成员计入失败比例上界。
- 合格候选中，第一名加权强涨贡献至少是第二名的 1.25 倍。同一方向连续六窗确认主线；最早在随后两个完整窗口支持沸点，不倒填确认窗口。
- 保持：同一方向 B≥55、M≥0、U≥10、C≥6、L≥1.3、相对强度≥0.3；当前涨停至少一只，或合格固定组 M≥−0.5、失败比例上界≤30%。连续两窗明确失效才退出；未知保留身份。

## 题材 V2.4

| 目标 | 主要进入条件 | 连续完整窗口 |
| --- | --- | ---: |
| 启动 | 稳定首板≥max(3,ceil(1%×N))；B≥55、M≥0、U≥5、D5<5；整理/退潮之后另需至少两只新首板 | 3 |
| 主升 | B≥60、M≥0.5、U≥15、D5<10；同限幅组至少一只首板、两只中板 | 3 |
| 主升：强普涨单中板 | B≥75、M≥1、U≥20、D5<5；稳定首板总数达到启动规模；同限幅组至少两只首板、一只中板 | 3 |
| 分歧 | 已有活跃周期，D5<15；同组有中/高板，并有晋级竞争、固定组收缩或高位负反馈；不属于中板耗尽且广泛走弱 | 2 |
| 高潮 | B≥75、M≥1.5、U≥30、D5<5；同限幅组至少两只首板、两只中板、一只高板 | 3 |
| 退潮 | B≤40、M≤−0.5；并有高位组、核心组、启动组失败，或活跃周期 D5≥15 | 2 |
| 急剧退潮 | B≤20、M≤−1.5、D5≥25 | 1 |
| 整理 | 涨停数≤max(2,ceil(1%×N))、无稳定中高板；A30≤1、abs(V30)≤0.3、Q10≤5；15 分钟无新增整组风险，且不满足启动形态 | 3 |

普通转换最短保持六个有效窗口（30 个交易分钟）；风险转退潮及活跃阶段转分歧可提前。主升、分歧、高潮按同一支持限幅组持续确认，不能用不同组轮换凑次数。表中是主要入口，下述风险、前态和恢复约束同时适用。

- 晋级竞争使用昨日 1—3 板固定晋级组：同限幅组至少一只稳定晋级，同时至少一只、且至少 30% 的固定组成员稳定受阻。受阻要求 r10≤−1，普通未涨停不算受阻。
- 高位风险固定组取昨日已确认 5 板以上及周期跟踪的高位成员；未涨停且 r10≤−3，或较已观察峰值回撤≥5，为个股失败。核心组、启动组整组失败分别要求至少两只且至少半数失败；缺价格不能当作无风险。
- 分歧恢复主升/高潮：实际目标支持组没有已确认竞争，三类整组风险明确清除，固定组收缩明确消失。主升保持继续检查当初支持组，另一限幅组竞争不单独推翻主升。
- 退潮恢复主升还需风险清除及 15 分钟无新增整组风险；退潮恢复分歧另需 B≥45、M≥−0.2、D5<10，确认提高为三窗。
- 连续六窗保持失效后，允许有证据退出：活跃周期 B≤40、M≤−0.5、中板消失，可两窗确认退潮；仍有中高板、D5<15，且 B<50 或 M<0 或 U<10，可两窗确认分歧。
- 主升/分歧持续失效后重启：无稳定中高板，达到启动形态，至少两只新首板不属于旧启动组且首次稳定出现晚于最后有效支持；三类整组风险清除、15 分钟无新增整组风险，连续三窗后建立新周期。
- 整理/退潮持续失效六窗后也可使用启动承接：启动形态、三类整组风险清除及 15 分钟无新增整组风险同时连续三窗成立。该承接分支不沿用普通启动的“两只首板最近 30 分钟首次出现”限制；在逐窗报告中标为“持续失效退出”。
- 整理退出须有新增下行证据：近 15 分钟新增整组风险、Q10≥10、新急剧退潮或 V30<−0.5，并满足对应退潮确认。旧跌停股当天反复开板/回封不重复计为风险范围扩大。

| 当前阶段 | 保持条件 |
| --- | --- |
| 启动 | B≥45、M≥−0.5、D5<10，稳定首板至少一只 |
| 主升 | B≥50、M≥0、U≥10、D5<15；原支持组板位股票至少两只，其中中/高板至少一只 |
| 分歧 | D5<20，仍有竞争/收缩/高位风险或有中高板支持的降温，不属于中板耗尽且广泛走弱 |
| 高潮 | B≥60、M≥0.5、U≥20、D5<10；原高潮支持组首、中、高板各至少一只 |
| 退潮 | B≤45 且 M≤−0.3，或三类整组风险任一成立 |
| 整理 | 涨停数≤max(2,ceil(1%×N))+1；A30≤1.5、abs(V30)≤0.5、Q10≤10，且不满足启动形态 |

固定组收缩使用已确认阶段的价格锚点和可比成员：相对基准上涨占比下降至少 15 个百分点，且强势占比下降至少 5 个百分点。跨日用已知日线参考价连接；午休不清空已确认身份。风险优先；在活跃阶段确认分歧后优先处理分歧，再判断高潮/主升，之后处理启动/整理。完整合法路径和三值逻辑以源码 `ALLOWED`、`Machine.tick` 为准。
